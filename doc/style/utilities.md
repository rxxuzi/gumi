# Utilities

## Border Utilities

```html
<!-- Border -->
<div class="border">All borders</div>
<div class="border-top">Top border</div>
<div class="border-bottom">Bottom border</div>
<div class="border-left">Left border</div>
<div class="border-right">Right border</div>
<div class="border-0">No border</div>

<!-- Border radius -->
<div class="rounded">Rounded corners</div>
<div class="rounded-circle">Circle</div>
<div class="rounded-pill">Pill shape</div>
<div class="rounded-0">No radius</div>
```

## Shadow Utilities

```html
<div class="shadow-sm">Small shadow</div>
<div class="shadow">Default shadow</div>
<div class="shadow-lg">Large shadow</div>
<div class="shadow-none">No shadow</div>
```

## User Select

```html

```

## Visibility

```html
<div class="visible">Visible</div>
<div class="invisible">Invisible (takes up space)</div>
<div class="d-none">Hidden (no space)</div>
```

## Text Utilities

```html
<!-- Text transform -->
<p class="text-lowercase">lowercase text</p>
<p class="text-uppercase">UPPERCASE TEXT</p>
<p class="text-capitalize">Capitalized Text</p>

<!-- Text decoration -->
<p class="text-decoration-none">No decoration</p>
<p class="text-decoration-underline">Underlined</p>
<p class="text-decoration-line-through">Strikethrough</p>

<!-- Text wrapping -->
<p class="text-nowrap">No wrap text</p>
<p class="text-truncate">Truncated text with ellipsis...</p>
```

## Screen Reader Utilities

```html
<!-- Screen reader only -->
<span class="sr-only">Only visible to screen readers</span>

<!-- Skip to main content link -->
<a href="#main" class="sr-only sr-only-focusable">Skip to main content</a>
```

## Print Utilities

```html
<div class="d-print-none">Hidden when printing</div>
<div class="d-none d-print-block">Only visible when printing</div>
```

## Responsive Utilities

```html
<!-- Hide on specific breakpoints -->
<div class="d-none d-sm-block">Hidden on xs</div>
<div class="d-none d-md-block">Hidden on xs and sm</div>
<div class="d-block d-lg-none">Hidden on lg and up</div>

<!-- Responsive text alignment -->
<p class="text-center text-md-left">Center on mobile, left on desktop</p>

<!-- Responsive spacing -->
<div class="p-2 p-md-4">Small padding mobile, large desktop</div>
```
